## Projenin Amacı

ReLoop, Türkiye tekstil sektöründeki üretim öncesi fireyi — temiz ve geri kazanılabilir ama alıcı bulamayan kumaş atığını — doğru alıcıyla otomatik ve güvenli biçimde buluşturan bir platformdur.

Fabrika fireyi fotoğraflar, yapay zekâ dijital bir Malzeme Pasaportu oluşturur, eşleştirme motoru en uygun alıcıyı bulur, kimlikler anlaşma sağlanana kadar gizli kalır, işlem tamamlanınca veriler anonim olarak kamu sistemine raporlanır.

Bu depo, projenin gerçekten çalışan uygulamasını içerir.

## Nasıl Çalıştırılır

### macOS

1. `baslat_mac.command` dosyasına çift tıklayın.
2. Uyarı çıkarsa: dosyaya sağ tıklayın, Aç'a tıklayın, tekrar Aç'a tıklayın.
3. Hâlâ açılmazsa Terminal'de şunu yazın: `chmod +x baslat_mac.command` sonra tekrar deneyin.
4. Tarayıcı otomatik açılır: http://127.0.0.1:8000/app

### Windows

1. `baslat_windows.bat` dosyasına çift tıklayın.
2. Uyarı çıkarsa: Diğer bilgiler, sonra Yine de çalıştır'a tıklayın.
3. Python kurulu değilse python.org adresinden kurun.

Kapatmak için pencereyi kapatın.
